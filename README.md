# 🧾 Sistem Layanan Pengaduan Online

Proyek ini merupakan **sistem layanan pengaduan berbasis website** yang dibangun menggunakan:
- ⚙️ **Java Spring Boot** sebagai backend  
- 💻 **React JS** sebagai frontend  

---

## 🚀 Fitur Utama
- Login sebagai **Admin** atau **Pelapor**
- Dashboard khusus untuk masing-masing peran
- Sistem pengaduan berbasis web yang mudah digunakan
- Sistem tampilan navbar dan footer profesional
- Navbar menu berfungsi semua
- Tampilan website menyesuaikan ukuran layar antara pc dan smartphone

---

## 🛠️ Cara Penggunaan

1. **Persiapan Database**
   - Buat database baru di MySQL (atau sesuaikan dengan konfigurasi).
   - Edit file `application.properties` pada backend agar sesuai dengan nama database dan kredensial kamu.

2. **Jalankan Backend**
3. - Buka Netbean IDE 25
   - Open Projek
   - Pada Projek Backend klik kanan lalu pilih run


4. **Jalankan Frontend**
   - Ketik di cmd sesuaikan dengan folder root anda
   - contoh : cd c/xampp/hdtocs/projek-anda/frontend
   - ketik enter lalu ketik NPM Start dan enter
  
5. **Cara lain jalankan frontend**
   - Buka netbean
   - Pilih open projek
   - pilih frontend
   - klik kanan pilih menu NPM Script>
   - Pilih NPM start
